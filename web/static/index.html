How VOX works
A manifest of audio files is distributed by Spark to parallel Python workers, each running the full pipeline.

    

      

        
Input
Audio corpus
manifest.csv

        
Driver
Spark DataFrame
repartition(N)
mapInPandas(udf)

        

          
Worker 1 — decode, 16 kHz, trim, normalise, ASR, score

          
Worker 2 — model loaded once, batched inference

          
Worker N — partitions processed in parallel

        

        
Output
Results
text, WER, CER, timing

      

      

        
01
Preprocessing
Decode to mono, polyphase resampling to 16 kHz, energy-based silence trimming at −35 dB, peak normalisation, optional noise at a target SNR, log-mel feature statistics.

        
02
Distributed inference
Arrow batches stream to Python workers; each loads the model once. Whisper detects English, Spanish or Japanese, or translates any of them to English.

        
03
Evaluation
Language-aware normalisation and Levenshtein alignment. WER over words for English and Spanish; Japanese is scored per character after converting kanji to kana.
